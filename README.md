# Day 36 — Flask Todo App (Full Stack)

**120 Days of Code** | NIT Rourkela | Mechanical Engineering

## What this is
A full stack todo app built with Python Flask backend
and HTML/CSS/JS frontend with SQLite database.

## How to run
```bash
pip3 install flask
python3 app.py
```
Then open http://localhost:5000 in your browser.

## Features
- Add, complete and delete todos
- Priority levels (High, Medium, Low)
- Due date support
- Filter by status and priority
- SQLite database storage
- REST API backend
